# 时间轴元素编号

这份编号**仅供人和 AI 沟通使用，不在页面上显示**。你说「T09 改高一点」「T03 那组按钮太挤」时，我按这张表直接定位代码元素。

## 规则

- 前缀 `T`（Timeline），两位数字，**只增不改**：已有编号永远不挪，新元素从第 14 号开始往后追加。
- 只覆盖**画布底部的时间轴面板**（含「时间轴」和「审阅」两个视图）；画布上的回放视觉（表节点「字段: 值」、值高亮、连线闪烁）不在本表内。
- 代码里每个元素带隐藏属性 `data-el="T0x"`，不影响显示、不影响点击。

## 常见指代示例

- 「T01 整条面板太高/太矮」→ 改 `.ms-timeline` 的最大高度与甘特区高度
- 「T03 那组按钮」→ 改播放/暂停、重播、重置的样式与顺序
- 「T09 的事件条颜色/播放头」→ 改甘特条与播放头样式
- 「T11/T12 两列比例」→ 改审阅视图左右列宽
